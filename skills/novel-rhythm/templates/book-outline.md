## 五、曲线自检

- [ ] 喘息章（张力 1）紧邻高潮章之后，无强钩
- [ ] 爽点每 3~5 章一个，类型轮换（过关 → 碾压 → 打脸 → 认可）
- [ ] 强钩章只放浪首 / 浪尾
- [ ] 每约 5 章一拍真惊悚
- [ ] 关键角色每 1~2 章一名，全部"场合顺带"登场
- [ ] 主视角 3~4 章后插视角章 / 群像喘息章
- [ ] 尾钩三选一轮换不重样（数值变动 / 谶语悬念 / 结果待验证）
