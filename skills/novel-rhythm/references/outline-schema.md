# 节奏档案数据格式（rhythm-data.json）

> 可视化数据规范。查看器 `tools/rhythm-viewer.html` 与本文件一一对应；生成节奏数据时严格按此结构输出。

---

## 二、字段说明

### meta（可选块，整体可省略）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | string | 否 | 曲线图标题，缺省显示"未命名项目" |
| subtitle | string | 否 | 副标题 |
| scale | string[] | 否 | 张力标尺说明，缺省用标准五档 |

### segments（分段/浪，可选）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | string | 是 | 段名（浪/区间/事件组名，如"危机浪""铺设段"） |
| from / to | number | 是 | 章号闭区间，画为曲线背后的背景色带 |

### chapters（章节节点，必填）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| no | number | 是 | 章号，按升序排列 |
| label | string | 是 | 节点标题（该章一句话名字） |
| template | string | 否 | 模板代号，"T1"~"T13" 或 "V1/V2" 变体 |
| type | string | 是 | 章型：钩子章/设定章/登场章/机制章/信息章/伏笔章/转折章/铺垫章/爽点章/高潮章/收获章/喘息章/铺设章/蓄力章/落地章 |
| tag | string | 否 | 类型单字（钩/设/喜/机/息/伏/转/铺/爽/收/蓄/惊），缺省按内置映射自动生成（如"钩子章"→钩、"爽点章"→爽），未命中时取 type 首字 |
| dir | string | 否 | 节点标记符（★/▲/▼），缺省按张力自动判定：≥4→★，3→▲，≤2→▼ |
| tension | number | 是 | 章张力，1~5 |
| tensionEnd | number | 否 | 高开低走章的收尾张力（如收获章 4→2 记 tension:4, tensionEnd:2），查看器画降段标记 |
| mood | string | 否 | 情绪基调（如"恐慌喜剧""压抑→希望"） |
| summary | string | 是 | 一句话功能（本章存在的理由） |
| hook | string | 否 | 章末钩（含钩子类型说明） |
| beats | object[] | 否 | 章内节拍数组；未展开的章可先省略 |

### beats（章内节拍，可选）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| name | string | 是 | 拍名（衔接拍/新要素拍/主事件拍/回落拍/尾钩拍 等） |
| tension | number | 是 | 该拍张力，1~5（用于画章内曲线） |
| desc | string | 是 | 一拍一句话内容 |

---

## 三、生成与使用规则

1. **只输出纯 JSON 文件**（UTF-8，文件名建议 `rhythm-data.json`）；不要在 JSON 里写注释。
2. 章节节点先排齐（工作流 A 完成后再出数据）；章内节拍可后补——**只更新对应章的 beats 数组即可**，不必重排全书。
3. 数据必须与节点表一致：`tension` 对齐 [rhythm-curve.md](rhythm-curve.md) 的曲线；节拍 `tension` 对照"章内曲线四型"检查。
4. 人名/场所/体系/事件必须遵守 [universal-slots.md](universal-slots.md) 的通用化规则（零专名）。
5. 使用方式：打开 `tools/rhythm-viewer.html` → 导入 JSON（拖拽 / 选择文件 / 粘贴文本皆可）→ 主视图看全书曲线 → 点击章节节点下钻看章内节拍曲线 → 可导出 SVG。
6. 内置示例：`tools/demo-rhythm-data.js`（查看器默认加载，含 20 章完整数据：节点 + 章内节拍 + 段带，可当生成模板参考）。

## 五、章节文件内节奏标注规范（写作实况查看器用）

`tools/written-rhythm-viewer.html` 读取章节文件（`.md` / `.txt`）时，**优先读文内标注，无标注才走估算**。让 AI 每写完一章，在文件开头补一行标注，实况曲线即转为精确值。

支持三种写法（任选其一，写在章节正文最前面即可；查看器解析前 40 行）：

### 写法一（推荐）：HTML 注释块

```html
<!-- rhythm: tension=4; type=落地章; template=T5; beats=3,4,5,3,3 -->
```

### 写法二：节奏标注行

```
【节奏标注】张力: 4 ｜ 类型: 落地章 ｜ 模板: T5 ｜ 节拍: 3,4,5,3,3
```

### 写法三：最简一行（只够标章级张力）

```
张力: 4
```

### 字段说明

| 字段 | 必填 | 取值 | 说明 |
|---|---|---|---|
| tension | 否 | 1~5 | 章级张力；缺省则取 beats 最高拍 |
| type | 否 | 钩子章/设定章/登场章/…（见上文章型全集） | 用于节点类型标记 |
| template | 否 | T1~T13、V1/V2 | 模板代号，用于详情与对照 |
| beats | 否 | 数字序列（逗号/空格/顿号分隔） | 章内节拍张力，1~5；直接画章内曲线 |

约定与约束：

1. **标注优先、估算兜底**：无标注的章由字数/对话占比/动作情绪词密度估算，界面会标"估算"提醒；趋势可看、精确值请回补标注。
2. **beats 可选**：只标 `tension` 也能出章节级曲线；章内曲线需要 `beats`，或由查看器自动按"场景分隔线 / 段落"切段估算。
3. 遵守 [universal-slots.md](universal-slots.md) 的零专名规则——标注里不写本名与专有身份，用章型（落地章 / 爽点章）与功能位描述。
4. 场景分隔线：章内用一行 `---` 或 `***` 等分隔线，查看器会按场景切段（估算更贴近真实节奏）。

**写作流程建议**：把这段规范喂给 AI——"每写完一章，依 `outline-schema.md` 第五节在正文开头补一行 `<!-- rhythm: ... -->` 标注"——已完结存稿也可让 AI 逐章回补。
